# Audit anti-slop 001 - 2026-10-21

Cakupan: `index.html`, `styles.css`, `app.js`, `dashboard.html`, `dashboard.css`, `dashboard.js`.
Mode: **after** (audit dulu, belum ada perbaikan).
Alat: `contrast-check.py` (skill antislop-human), Edge headless via CDP (tap target, tab order, overflow, console), pembacaan kode.

Tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

---

## HIGH

### 1. R-02 - em dash di teks yang ditulis agen
- Bukti: `app.js:469` `"\" — ubah isian di bawah, lalu tekan Simpan perubahan."`; `dashboard.css:1` komentar.
- Dampak: aturan Hard Gate, karakter `—` dilarang di teks apa pun yang ditulis agen.
- Perbaikan: ganti dengan titik dua atau koma. `"… ubah isian di bawah, lalu tekan Simpan perubahan."`

### 2. R-03 - tap target di bawah 44 px
- Bukti (390 px, Edge):
  - `index.html`: 101 dari 104 target di bawah 44 px. Tombol `Edit` 47x32, `Hapus` 60x32, tombol header 42 px, input 40-41 px.
  - `dashboard.html`: 8 dari 8 target di bawah 44 px. `select` 38 px, tombol 40 px.
- Dampak: Hard Gate. Di layar sentuh, target 32-40 px sulit ditekan.
- Perbaikan: `min-height: 44px` untuk `.btn`, `.btn-edit`, `.btn-del`, `.btn-sm`, `input`, `select`; atau naikkan hit box dengan padding.

### 3. R-25 - kontras teks aksen di atas accent-soft gagal AA
- Bukti: `#c2410c` di atas `#fbe9e0` = **4.40:1** (butuh 4.5:1).
  Dipakai oleh badge `Aplikasi` (11.5 px) dan baris selisih `-7,5 menit (-22,3%)` (12.5 px).
- Dampak: Hard Gate. Teks normal gagal ambang.
- Perbaikan: gelapkan teks menjadi `#a3350a` (atau `--accent-ink` di atas latar penuh), atau turunkan lightness `--accent-soft`.

## MEDIUM

### 4. R-25 - batas kontrol di bawah 3:1 (non-text, WCAG 1.4.11)
- Bukti: `--line-strong` `#b9b2a3` di atas `#ffffff` = **2.11:1**; `#4a463b` di atas `#201e19` = **1.77:1**.
  Dipakai sebagai border input, `select`, dan tombol ghost.
- Dampak: batas kontrol sulit ditemukan pengguna low-vision.
- Perbaikan: naikkan `--line-strong` ke sekitar `#8f887a` (light) dan `#6b6457` (dark), atau beri border 2 px.

### 5. R-01 / R-31 - garis kiri dekoratif pada kartu KPI
- Bukti: `dashboard.css:239` `.kpi { border-left: 3px solid var(--accent); }` pada keenam kartu.
- Alasan gagal: garis itu tidak menandai state apa pun; hanya menghias. Enam garis identik = dekorasi, bukan sinyal.
- Perbaikan: hapus `border-left`, atau pakai hanya pada satu kartu yang memang berbeda statusnya.

### 6. R-05 / C-3 / R-20 - hierarki dashboard tidak mengikuti pertanyaan layar
- Bukti: enam kartu KPI identik di baris teratas; pertanyaan utama pengguna (rata-rata sebelum vs sesudah aplikasi) berada di kartu 2-span di kanan bawah.
- Alasan gagal: bentuknya "sidebar + stat row + chart + table" versi tanpa sidebar; yang dipentingkan adalah yang paling sering dibaca, dan itu bukan yang di atas.
- Perbaikan: jadikan blok perbandingan manual vs aplikasi sebagai fokus (posisi atas, lebar penuh, angka besar), KPI sisanya jadi ringkasan sekunder.

### 7. R-27 - state error dashboard tanpa aksi
- Bukti: `dashboard.js` menampilkan `"Gagal memuat data: " + pesan` tanpa tombol apa pun. Halaman input punya tombol `Coba lagi`.
- Alasan gagal: state error wajib menyebut sebab dan langkah berikutnya.
- Perbaikan: tambahkan tombol `Muat ulang` di dalam state error.

### 8. R-20 / R-31 - motif identitas tidak konsisten antar halaman
- Bukti: `styles.css:148-158` `.rule` = tick ruler (motif "durasi/ukuran", ada alasan tertulis); `dashboard.css:140` `.rule` = gradien 3 px aksen.
- Alasan gagal: elemen dengan nama sama punya bahasa visual berbeda; motif yang jadi identitas hanya hidup di satu halaman.
- Perbaikan: pakai tick ruler yang sama di dashboard, atau hentikan pemakaian gradien.

### 9. R-32 - segmen internal input tanggal/jam fokus tanpa ring
- Bukti: Tab berurutan pada `input#tanggal`, `#d1_mulai`, `#d1_selesai`, `#d2_mulai`, `#fFrom`, `#fTo` menghasilkan stop kedua dengan `outline: none 3px`.
- Alasan gagal: fokus berpindah ke bagian dalam kontrol tanpa indikator terlihat.
- Perbaikan: `input:focus-within { outline: 2px solid var(--focus); outline-offset: 2px; }`.

## LOW

### 10. R-06 - label uppercase ber-tracking
- Bukti: `styles.css:322`, `:468`, `:578`; `dashboard.css:202`, `:251`, `:381`. Tracking .03-.04em (ringan).
- Catatan: konvensi label form/tabel, bukan eyebrow pemasaran. Tetap disarankan melepas uppercase pada `.kpi-k` (enam label statistik) agar tidak terbaca sebagai template.

### 11. R-12 - border dan shadow dipakai bersamaan di setiap kartu
- Bukti: `.card { border: 1px solid var(--line); box-shadow: var(--shadow); }` di kedua stylesheet.
- Alasan gagal: dua penanda elevasi untuk hal yang sama; shadow jadi default, bukan penanda.
- Perbaikan: pertahankan border, hapus shadow (atau sebaliknya).

### 12. R-05 - judul chart berupa label, bukan pertanyaan
- Bukti: "Komposisi proses", "Tren durasi harian". Chart menjawab pertanyaan yang tidak tertulis.
- Perbaikan: "Porsi waktu Proses 1 vs Proses 2", "Durasi per tanggal, 2-21 Okt".

### 13. Defect kode - kelas `.muted` tidak terdefinisi di dashboard
- Bukti: `dashboard.js:577`, `:605` memakai `<td class="muted">`; `dashboard.css` tidak punya `.muted`.
- Dampak: sel "Tidak ada data." tampil tanpa gaya, bukan error.
- Perbaikan: tambahkan `.muted { color: var(--ink-soft); }` di `dashboard.css`.

### 14. R-32 - tidak ada skip link di halaman panjang
- Bukti: dashboard punya filter, 6 KPI, 4 chart, 2 tabel; Tab dari awal harus melewati seluruh header dan filter.
- Perbaikan: tautan "Lewati ke ringkasan" ke `#kpis` sebagai elemen fokus pertama.
